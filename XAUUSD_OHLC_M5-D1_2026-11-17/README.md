# XAUUSD OHLC 多周期数据（Infinox MT5）

从 Infinox MT5 终端（服务器 `InfinoxLimited-MT5Live`）导出的 XAUUSD OHLC 历史，周期覆盖 5 分钟到日线。

- 导出时间：2026-11-17 06:14 UTC（快照日 2026-11-17）
- 格式：Parquet，zstd 压缩，每周期一个文件
- 目录命名：`<周期>_<起始日>_<结束日>`

## 目录结构

```
XAUUSD_OHLC_M5-D1_2026-11-17/
├── M5_2018-09-14_2026-11-17/
│   └── XAUUSD_M5.parquet
├── M15_2018-09-14_2026-11-17/

├── M30_2018-09-14_2026-11-17/

├── H1_2018-03-19_2026-11-17/

├── H4_2018-03-19_2026-11-17/

├── D1_2007-06-22_2026-11-17/

├── manifest.json
└── README.md
```

## 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| time_utc | datetime64[us, UTC] | bar 开盘时间，真 UTC |
| time_server | datetime64[us] | MT5 券商墙上时钟（bar 开盘） |
| open / high / low / close | float64 | 报价 |
| tick_volume | int64 | MT5 tick 计数 |
| spread | int32 | 点差（points） |
| real_volume | int64 | 该品种为 0 |

## 覆盖说明

- D1 自 2007-06-22（券商时间）起完整。
- M5 / M15 / M30 的真 5 / 15 / 30 分钟粒度自 2018-09-14 起。
- H1 / H4 自 2018-03-19 起。
- 券商更早的存档只有每日一根快照（M30 早期甚至是每小时一根），为保证文件内粒度一致，这些稀疏段落已剔除。
- 每个文件最后一根是导出时仍在形成的 bar。

## 时区

- 券商服务器时间：冬令时 UTC+2，夏令时 UTC+3，跟随美国夏令时（3 月第二个周日到 11 月第一个周日）。
- `time_utc = time_server − 偏移`；`time_server` 保留原始券商时间。

## 校验结果

- 重复时间戳 0，时间单调递增，OHLC 违规 0，非正价格 0
- 工作日中位 bar 数：M5 276、M15 92、M30 46、H1 23、H4 6
- M5 聚合日收盘与 D1 收盘对比 2,110 个交易日，平均绝对差 0.0001，最大 0.24（仅当天未完成 bar）
- 超过 72 小时的缺口共 15 处，均为圣诞与新年休市

## 用法

```python
import pandas as pd

df = pd.read_parquet("XAUUSD_OHLC_M5-D1_2026-11-17/M5_2018-09-14_2026-11-17/XAUUSD_M5.parquet")
df = df.set_index("time_utc").sort_index()
print(df.close.resample("1D").last().tail())
```
